# Changelog

## Phase 1 release (November 2026)

### Added
* **Solution B**, the minimum viable platform (`infrastructure/solution-b/`):
  * one account with an encryption key, audit trail, threat detection, a
    private network with flow logs, a hardened data bucket, GitHub deploy
    roles and a budget alert
  * 48 resources in about 5 minutes; an optional demo web page
* **Solution A**, the full landing zone (`infrastructure/solution-a/`):
  * people and groups in IAM Identity Center, then an AWS Organization with
    six accounts and four guardrails
  * a Security account holding locked audit logs, GuardDuty, Security Hub,
    Config and Access Analyzer for the whole organisation
  * one configurable workload for dev, staging and prod: ECS Fargate behind
    a load balancer and web firewall, a private PostgreSQL database, auto
    scaling
  * `lz-dev.ps1`: the landing zone and dev up, down or status in one command
* Nine tested modules shared by both solutions (`infrastructure/modules/`).
* CI on every change: format, validate, mocked module tests and a Trivy
  scan. A nightly drift detection workflow, ready for environments that
  stay deployed (none is enrolled yet).
* Runbooks for bootstrap, both deployments, both demos and teardown.
* The eight deliverables in `docs/`, with evidence: deployment logs,
  redacted console screenshots and the Implementation Guide checklists.
* The engineering handbook (`docs/handbook/`), project definition, way of
  working, twelve decision records, the Phase 1 sprint record and meeting minutes.
* Issue and pull request templates and Dependabot.
* Terraform standards (`docs/standards/`): nine short rule pages, from
  directory structure to testing, replacing the single naming guide.
* Module READMEs: a real usage example and a reference section generated by
  terraform-docs, checked in CI (the **Module READMEs** job).
* Governance, risks and ethics (`docs/project/governance-risks-ethics.md`):
  decision rights, change control, access, cost, confidentiality, AI use,
  ethics, and one live risk register (R01 to R17).
* A **CI passed** summary job, a README for the workflows, a concurrency
  group on the drift check, and a documentation-request issue template.

### Changed
* `envs/poc/` renamed `solution-b/`, and Solution A's per-environment
  folders folded into one workload
  ([ADR 0004](docs/decisions/0004-one-workload-per-environment.md)), 14 Oct 2026.
* tfsec replaced by Trivy
  ([ADR 0011](docs/decisions/0011-trivy-on-every-change.md)), 14 Oct 2026.
* State locking moved from DynamoDB to S3's native lock file, 28 Sep 2026.
* The accounts now stay between demos, and only what costs money is torn
  down ([ADR 0010](docs/decisions/0010-keep-accounts-between-demos.md)),
  18 Oct 2026.
* `docs/` consolidated, 1 Nov 2026: one page per deliverable in
  `docs/deliverables/` (deliverable 6 now holds the threat model, risk
  assessment and risk management plan; deliverable 3 holds the scan findings),
  one Phase 1 sprint record, one Phase 1 meetings file grouped by sprint, and
  images and diagrams in `docs/media/`.

### Fixed
* Five problems found by the manual security review, including GitHub's
  read-only role being able to read stored data, 7 Oct 2026
  ([scan findings](docs/deliverables/security-controls.md#scan-findings-register)).
* Two settings that drifted from the code on a redeploy, 18 Oct 2026.
* `lz-dev.ps1 down` now also turns off GuardDuty and Security Hub in the
  management account, which kept billing after a teardown, 1 Nov 2026.
