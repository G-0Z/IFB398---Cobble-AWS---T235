# IFB398-T235 Sprint Plan

## Phase 1 and Phase 2 sprints

IFB398 Capstone · Team T235 · P608 Cobbled AWS Platform Configuration

Phase 1 runs six two-week sprints from 17 August to 8 November 2026. Phase 2 plans eight sprints from 15 February to 28 May 2027, with four client gates (G0 to G3).

### How sprints run

- Sprints are tracked in the GitHub project "Team Planning", using a Sprint iteration field, start and target dates, and Todo, In progress and Done status.
- Each sprint opens with planning at the weekly Discord meeting and closes with a review at the next one.
- Phase 2 work is labelled "phase 2" on the tracker and gated by client sign-off at G0 to G3.
